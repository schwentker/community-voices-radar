# Community Voices Radar UI

Static frontend for the `community-voices-radar` MCP demo.

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Local development

```bash
npm run dev
```

The app fetches community posts directly from:

- `https://community-voices-radar.fly.dev/community-posts`

Build output is generated in `dist/` and can be deployed as static files under `/community-voices-radar/`.
